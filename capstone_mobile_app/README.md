# Capstone Market — Application mobile

Application Expo/React Native complète pour le projet Capstone.

## Fonctionnalités

- Inscription avec validation et gestion des erreurs
- Connexion avec validation et gestion des erreurs
- Écran d'accueil avec logo et produits
- Écran de détail d'un article
- Favoris persistants avec AsyncStorage
- Intégration d'une API externe (DummyJSON Products)
- Menu Paramètres
- Écran Paramètres
- Notifications locales et notification de test
- Déconnexion
- Persistance de session

## Lancer le projet

```bash
npm install
npx expo start
```

Puis :
- `a` pour Android avec Expo Go/émulateur
- `i` pour iOS
- `w` pour navigateur

## API

L'application utilise :

`https://dummyjson.com/products?limit=20`

Aucune clé API n'est nécessaire.

## Comptes de démonstration

Tu peux créer un compte directement dans l'application.
